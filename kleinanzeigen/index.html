Available tools

Your AI assistant can call any of these tools through the MCP server:

Search listings

Search Kleinanzeigen by keyword, category, and location. Filter by price range. Returns titles, prices, locations, thumbnails, and listing IDs.

Connect the MCP server

Add this to your MCP client configuration:

{
  "mcpServers": {
    "kleinanzeigen": {
      "url": "https://mcp.beatanalytics.org/kleinanzeigen",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

Works with Claude Desktop, Claude Code, Cursor, Windsurf, and any MCP-compatible client.
